# Taste

## UI / UX
- Prefers a clean, minimal white web UI for the CLI's UI command, with menu-based navigation. Confidence: 0.6
- Prefers the Dashboard to list all sites flat (not grouped by server), while a Server menu shows each server with its site count and provisioned-at date. Confidence: 0.7
- Prefers rendering the configuration (YAML) in a polished web format in the browser so users can see sites and servers visually rather than as raw text. Confidence: 0.6
